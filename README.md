# 🍉 合成大西瓜 - 雲端連線版 (Cloud Multiplayer Edition)

這是一個基於 HTML5 Canvas 與 Matter.js 物理引擎開發的網頁版「合成大西瓜」遊戲。

本專案歷經多次迭代與優化，從最初的單機小品，一步步解決了 Emoji 貼圖與物理邊界不符的技術痛點，並正式導入 Google Firebase 雲端資料庫，實現跨設備遊玩與全球即時排行榜。這是一份記錄完整進化過程的實作專案！

---

## ✨ 核心技術與特色

* **精準物理碰撞：** 採用 HTML5 Canvas 裁切遮罩（Clipping Path）技術，強制將不規則的 Emoji 表情包完全收納在完美的物理圓形半徑內，做到視覺與物理引擎的 100% 同步。
* **視覺化安全範圍：** 針對高階水果（葡萄、大西瓜）額外繪製專屬的半透明 UI 碰撞光圈，拒絕空氣牆判定，提升玩家的策略判斷依據。
* **雲端即時存檔：** 串接 Firebase Firestore 資料庫，解決傳統 LocalStorage 無法跨設備的問題。只要記住帳號密碼，換手機、換電腦都能無縫接軌，保留最高分紀錄。
* **全網世界排行榜：** 首頁內建全球同步的前五名積分排行榜，運用資料庫即時監聽（onSnapshot），隨時隨地與各路玩家一同競技。
* **響應式浮動介面：** 遊戲內的 UI 資訊（排行榜、提示框）採用浮動絕對定位，並支援點擊折疊功能，確保在任何尺寸的手機螢幕上都不會擠壓到遊戲主畫布。
* **PWA 支援：** 結合 Service Worker 與 Web Manifest，玩家可將遊戲直接安裝至手機桌面，享受無網址列的全螢幕沉浸體驗。

## 🔄 版本更新與修改紀錄 (Changelog)

本專案在開發過程中經歷了幾次關鍵的痛點解決與架構升級：

### v2.1.0 介面重構與響應式修復 (UI/CSS Fixes)
* **修復：** 解決新增排行榜與提示框後，在部分手機設備上會將 Canvas 遊戲畫布向下擠出螢幕的問題。
* **優化：** 將所有遊戲內 UI（包含頂部資訊、左右側面板）改為絕對定位（Absolute Position），使其宛如貼紙般懸浮於畫面之上。
* **新增：** 實作面板折疊功能（Toggle Box），點擊標題即可收起詳細資訊，避免遮擋玩家視線。

### v2.0.0 雲端連線大升級 (Cloud Multiplayer Update)
* **重構：** 徹底移除原本依賴本地端 `localStorage` 的單機存檔機制。
* **新增：** 導入 Google Firebase (Firestore) 作為雲端資料庫。
* **新增：** 實作跨設備的帳號註冊與登入系統。
* **新增：** 全網即時「世界排行榜」，玩家可與其他設備上的朋友零時差比拼分數。

### v1.5.0 物理與視覺終極對齊 (Physics & Visual Sync)
* **痛點解決：** 解決過去因 Emoji 自身形狀不規則（如葡萄、西瓜），導致「視覺上未碰到，但物理引擎已判定碰撞/死亡」的嚴重不公平感。
* **技術突破：** 引入 Canvas `clip()` 裁切魔法，將 Emoji 強制裁切成對應物理引擎半徑的完美圓形。
* **優化：** 優化死亡線判定邏輯，改為偵測水果的最上緣（Top Edge），而非圓心，讓堆疊極限更為精準。

### v1.0.0 初始單機版 (Initial Local Release)
* 完成 Matter.js 基礎剛體物理建置。
* 實作滑鼠/觸控追蹤與水果掉落、合成邏輯。
* 完成 PWA 基礎設定。

## 🎮 遊戲玩法與進化鏈
